# Eastside Active Dad Map

## Add venue photos

1. Upload JPG, PNG, or WebP photos to `public/venues/` in GitHub. Give each file a clear name, for example `robinswood-playground-01.jpg`.
2. In `data/venues.json`, add the paths to the relevant venue. Use paths that start with `/venues/`:

```json
"photos": [
  "/venues/robinswood-playground-01.jpg",
  "/venues/robinswood-playground-02.jpg"
]
```

3. Commit the edit. Vercel automatically deploys the photo gallery.

Keep photos reasonably small (ideally under 2 MB each) so the map remains fast on mobile.
